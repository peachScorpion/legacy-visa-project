04

特殊规则与注意事项

⚠ 签证费不退

预约完成后领馆全额收取签证费（B1/B2: 185美元/约¥1300），任何情况下无法退款。即使拒签也不退还。

⚠ 改期费用

如需更改面谈时间，通常需支付额外预约更改费（约100元/次），由ustraveldocs.com系统收取。

✓ 14周岁以下儿童免面签

14周岁以下儿童可免于亲自前往使领馆面签，由监护人或同行人代为递交材料。80周岁以上老人同样适用免面签。

⏱ 尽早规划

建议至少提前3个月开始准备。收齐材料到通知面试约需3-5个工作日，面试日期本身可能在30天后，旺季更长。

📋 材料真实性

所有提交的材料必须真实，这是签证审核的核心。虚假材料将导致拒签且可能影响后续申请。

📝 EVUS登记

持有10年有效B1/B2签证的中国公民，赴美前必须完成EVUS（签证更新电子系统）登记。自2025年10月1日起收费30美元。

🏢 使领馆管辖范围

根据客人户籍或常住地确定使领馆：北京、上海、广州、沈阳、武汉。不同领馆管辖不同区域，不可随意选择。

👥 人群差异化材料

按人群类型（在职/退休/学生/儿童/自由职业）提供差异化材料清单：身份证明、工作/学习证明、财力证明、行程与邀请证明。

📄 DS-160确认页

DS-160表格填妥后生成带条形码的确认页，是面签必备文件。表格内容必须真实准确，直接影响签证官判断。

🔍 行政审查

少数申请进入行政审查（Administrative Processing），审理时间可能延长至1-2个月。审查结果可能通过或拒签。

05

流程逻辑验证

闭环验证结果（v4.1 全链路版本 · 6泳道 · 主流程图订单状态嵌入业务节点 · 独立订单状态流转图五阶段三终态）

✓ 前期咨询与评估完整

B端有米小程序接待客户后新增咨询评估节点（了解出行目的/按户籍确定使领馆），C端悠哉小程序新增了解签证要求节点。下单前完成咨询闭环。

✓ 人群差异化材料清单

生成材料清单节点增加按国家+人群（在职/退休/学生/儿童）差异化，确保不同人群材料要求准确下发。

✓ DS-160填表+确认页

AI填表节点明确标注填写DS-160+翻译/校验+生成DS-160确认页(条码)，确认页是面签必备文件。

✓ 代缴签证费环节

新增代缴签证费节点（185美元/约¥1300），标注费用一经缴纳概不退还，操作人员代为在线支付。

✓ 在线预约面签

新增在线预约面谈时间节点（登录ustraveldocs.com·关联DS-160编号·生成预约确认页），面签日期可能排至30天后。

✓ 面签前培训

新增发送确认+面签培训节点，将DS-160确认页和预约确认页发送给客户，提供电话/当面培训讲解常见问题。

✓ 面签流程细节

新增客户前往使领馆面签（Lane4，携带材料）和面签流程（Lane6，安检→指纹→面谈10-15分钟）两个节点，清晰区分客户行为与领馆流程。

✓ 三分支签证结果

领馆审核结果从二分支扩展为三分支：通过→护照贴签；拒签→接收拒签理由单→UOM退款→退款结案；行政审查→等待1-2月→回到审核。

✓ 护照返还与核对

新增护照返还+核对节点（Lane4），快递或中信银行返还，客人核对签证页个人信息，确保护照安全交付。

✓ EVUS登记

新增EVUS登记节点，10年B1/B2签证赴美前必登记，2025年10月起收费30美元，确保赴美合规。

✓ 独立订单状态流转图

订单状态以 订单:xxx 格式标注于主流程图各业务节点下方（偏左避免流程线遮挡），颜色区分状态类型（橙=进行中、蓝=等待客户、紫=审核中、绿=已通过、红=异常）。详见 Section 02b 订单状态说明表。同时保留独立订单状态流转图（Section 03），按五阶段生命周期展开，含双循环容错和三终态。

✓ 特殊规则标注

新增特殊规则与注意事项章节，覆盖签证费不退、改期费用、儿童免面签、尽早规划、材料真实性、EVUS登记、使领馆管辖、人群差异化等10项规则。

✓ 异常分支完整（7条）

资质审核不通过→退回供应商；产品审核不通过→退回修改；下单校验不匹配→退回重选；材料不合格→退回补充；拒签→退款结案；行政审查→等待重审；材料退回→补充后重审。七条异常路径均有终止节点。
